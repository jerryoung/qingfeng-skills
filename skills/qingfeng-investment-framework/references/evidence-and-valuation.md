# 证据、财务与赔率准出

## 一、证据账本

对每个会改变结论的论断记录：

| 字段 | 要求 |
|---|---|
| 标签 | `事实` / `解释` / `假设` / `未知` / `冲突` |
| 定位 | URL 或本地文件，页码/表格/段落 |
| 时间 | 发布日、数据期、当前性 |
| 口径 | 币种、单位、合并范围、GAAP/IFRS/调整后、是否审计 |
| 独立性 | 是否来自独立经济主体或同一底层数据 |
| 论文作用 | 支持、反证、只生成待核验问题 |

来源层级：

1. 交易所/监管披露、审计报告、法规和法院文件；
2. 公司 IR、业绩会、客户/供应商正式披露、行业协会原始数据；
3. 可追溯数据库、统计机构、严肃媒体和专业调研；
4. 券商观点、博客、视频、社交媒体和匿名传闻只生成核验问题。

重复调用同一数据库、转载同一公告或重复公司口径不算独立验证。

冲突处理顺序：期间 → 币种/单位 → 定义 → 合并范围 → 会计口径。以一手披露锚定历史基线；无法调和且足以改变结论时，保留 `冲突`，停止数值估值，状态设为 `RESEARCH_MORE`。

## 二、财务三层验证

非金融企业：

1. **生存**：可用现金、债务期限、担保/契约、租赁、或有义务和再融资依赖；
2. **质量**：收入确认、应收账龄、存货减值、利润到现金、资本化、一次性项目、审计与关联交易；
3. **复利**：增量 ROIC、维持/增长 Capex、营运资本、再投资空间、普通股东现金、回购、稀释和每股价值。

金融企业先建立行业校准卡，用资本充足、资产质量、偿付能力和可分配利润替代普通 ROIC/FCF/净债务框架。

比率必须解释分子、分母和业务机制。高 ROE 可能来自杠杆或周期高点；负 FCF 可能来自高回报扩张，也可能是经营恶化。

## 三、资本配置机会成本

对每个资金去向记录：投入金额、预期现金流、回报周期、成功概率、失败残值和可观察里程碑。

在可比口径下比较：

```text
概率加权内部项目回报
vs. 并购回报
vs. 还债的确定回报
vs. 低估回购的每股价值回报
vs. 分红后股东可自行配置的回报
```

尚无回报数据的新项目只能作为期权，并以里程碑释放估值，不将战略必要性直接视为价值创造。

## 四、反向估值与目标回报门槛

先从当前市值/企业价值反推市场要求的收入、利润率、现金流、增长年限和终值。

对“当前 PE → 未来 PE”的简化场景，在不考虑期间分红时，达到目标年化回报 `r` 所需的每股盈利增速：

```text
required_growth = (1 + r) × (current_PE / terminal_PE)^(1 / years) - 1
```

有分红、回购、稀释或净债务变化时，改用完整每股现金流/股东总回报模型，不在简化公式里隐藏。

反向结果必须再与行业容量、份额、利润率、资本需求和增量 ROIC 交叉验证。“市场隐含低增长”不等于“能达到用户目标回报”。

## 五、正向情景与价值桥接

熊/基准/牛至少显式输入：

- 客户、量、价、份额和容量；
- 利润率、维持/增长投入和税率；
- 增量资本、再投资率和现金转化；
- 必要回报/折现率与终值假设；
- 离散的监管、技术、退市或治理风险；
- 预测期分红、回购、股权激励和完全稀释股本。

价值桥：

```text
经营/分部价值
→ 企业价值
→ 净债务或行业适配资本调整
→ 少数股东、非经营资产、或有义务和期权
→ 完全稀释普通股价值
→ 每股价值
→ 情景年化股东回报
```

熊情景应表达“公司仍存在，但利润率/增长/资本回报回归平庸”，除非有真实的生存风险，不用归零代替严格压力测试。

## 六、计算与准出

影响结论的计算必须：

- 使用可复现的计算器、表格、Decimal 或代码；
- 保留原始输入、公式、单位、汇率日期和输出；
- 用第二种方法复核市值、每股价值、年化回报与关键敏感性；
- 数值异常或 `null` 保留为缺失，不当作 0；
- 报告保留数据截止日和模型版本。

准出要求：

1. 会改变结论的历史数字有一手基线，当前数字有时间戳；
2. 重大未解决证据/口径冲突为零；
3. 核心主张与财务痕迹一致；
4. 资本配置已比较机会成本并桥接至每股价值；
5. 模型参数有理由、区间和敏感性；
6. 最强反方、未知与脆弱点已披露。

任一项重大未通过，估值标记“未准出”，状态不高于 `RESEARCH_MORE`。
