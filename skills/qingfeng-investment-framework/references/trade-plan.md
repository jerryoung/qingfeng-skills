# 非执行性交易计划

在用户要求建仓、加仓、减仓、退出、价格区间或分批数量时读取本文件。交易计划是等待人工确认的研究产物，不是订单。

## 一、行动资格

生成数值建仓计划前必须同时满足：

- 公司质量为 `PASS`；
- 价格赔率为 `ATTRACTIVE`，或用户明确要求为 `FAIR` 标的建立观察计划；
- 组合适配为 `FIT`，组合政策与资金来源完整；
- 估值、复权 OHLCV、成交量、费用和最小交易单位均有当前数据；
- 没有未解决的结构性论文、治理或重大口径冲突。

`FAIL`、`UNPROVEN`、`UNPRICED`、`UNFAVORABLE`、`UNKNOWN` 或 `CONSTRAINED` 不能被技术金叉、筹码峰或价格下跌提升为可建仓。未准出时只给补证清单、观察条件和 `NO_ACTION`。

## 二、从价值到价格带

按固定层级构建，而不是先找图形再讲故事：

```text
必要回报与情景估值 → 最高可接受价格 P_max
标的波动率/ATR → 区间宽度
支撑阻力/成交量分布 → 候选价格区域
日线与周线趋势/量价 → 批次顺序与等待条件
```

- 技术支撑高于 `P_max`：不买；
- 价格低于 `P_max` 但下跌原因未知或趋势加速恶化：观察或小额试仓，不机械补仓；
- 不输出单点“最佳买价”，而输出观察区、试仓区、确认区、完成区、暂停区和失效区；
- 所有历史价格使用一致的复权口径，当前真实委托价格使用未复权交易口径并显式桥接。

## 三、默认三阶段建仓

目标仓位由 [portfolio-policy.md](portfolio-policy.md) 计算。默认：

| 阶段 | 目标仓位份额 | 最低条件 |
|---|---:|---|
| 试仓 | 25% | 五闸门准出、价格低于上限、组合有额度、数据当前 |
| 确认仓 | 35% | 原论文未损且经营证据增强或交易结构改善 |
| 完成仓 | 40% | 论文、赔率、风险预算、资金来源与执行结构仍同时成立 |

每批开始前重新检查资格。未满足条件的批次保留为现金，不因预设比例机械执行。初次试仓同时受组合净值 2.5% 默认上限约束。

使用计算器时：

```bash
python3 scripts/trade_plan_calculator.py \
  --portfolio-value 1000000 \
  --entry-price 50 \
  --invalidation-price 42 \
  --loss-budget-pct 1 \
  --requested-target-weight-pct 10 \
  --hard-weight-cap-pct 15 \
  --lot-size 100
```

示例参数只演示算法，不是对任何证券的建议。

## 四、每批加仓前置条件

每批必须同时满足：

1. 原论文未受损，经营或治理没有新增红线；
2. 当前价格仍低于估值上限，必要回报仍达标；
3. 组合损失预算、共同因子、现金和流动性仍有额度；
4. 当前行情、复权和筹码数据未过期；
5. 下跌或波动原因已解释；
6. 经营证据增强或交易结构改善至少出现一项。

不能解释的下跌进入 `REVIEW`，不自动视为更高安全边际。

## 五、减仓与退出矩阵

| 触发原因 | 计划状态 | 默认动作 |
|---|---|---|
| 论文破裂/治理红线 | `EXIT` | 取消待买计划，形成流动性约束下的退出草案 |
| 论文受损、仍待补证 | `STRATEGIC_REDUCE` | 暂停加仓，参考减至原目标仓位 50% |
| 估值回报低于门槛 | `STRATEGIC_REDUCE` | 先退出交易仓，再降核心仓至新目标权重 |
| 组合硬约束超限 | `STRATEGIC_REDUCE` | 优先减弱论文、低赔率和高共同暴露标的 |
| 仅技术/筹码走弱 | `TACTICAL_REDUCE` | 暂停加仓；交易仓参考减 25%—50%，核心仓不自动卖出 |

价格离开原买入区不等于卖出理由。买卖尽量使用同一组论文变量；动作比例是默认草案，仍需用户确认和市场约束复核。

## 六、止损与损失预算

- 交易仓可用结构位或 ATR 定义价格失效条件；
- 核心仓不使用全市场统一百分比止损，以论文失效、熊情景和组合损失预算为主；
- 预计标的损失超过组合净值 1% 时，冻结新增批次并进入强制复核；
- 价格下跌同时触发论文破裂时，取消全部补仓计划，不用更低价格覆盖错误论文。

## 七、有效期与异常市场

计划默认有效 5 个交易日，并在以下事件中提前失效：财报/预告/重大公告、价格越过计划区域超过 1 ATR、分红拆股配股或复权变化、成交量/波动状态显著改变、论文/估值/组合额度变化、任何关键数据过期。

异常处理：

- 向上跳空越过买入区：不追价，暂停剩余计划；
- 向下跳空穿过失效区：取消加仓，先复核事件和论文；
- 停牌、涨跌停或市场不可交易：冻结计划，不盲目重试；
- 部分成交：只按用户提供或系统可验证的实际成交更新权重与风险预算；
- 复牌、公司行动或重大事件后：重新完成估值、技术和组合检查。

## 八、费用与流动性

计划纳入佣金、当地税费、买卖价差和预估滑点。默认单日计划量不超过近 20 日平均成交量的 5%；若退出预计需要多个交易日，披露正常/压力流动性下的退出天数并下调仓位。

## 九、Order Intent 契约

每一批至少输出：

| 字段 | 要求 |
|---|---|
| 状态 | `DRAFT · REQUIRES_USER_APPROVAL · NOT_AN_ORDER` |
| 标的/市场 | 证券代码、上市地、币种、最小交易单位 |
| 方向/仓层 | 试仓/确认/完成/战术减仓/战略减仓/退出 |
| 目标 | 价格带、股数、金额、组合权重 |
| 前提 | 公司、赔率、组合与执行数据状态 |
| 触发器 | 哪些事实或价格结构允许进入本批 |
| 取消/重算 | 论文、估值、组合、数据和市场异常条件 |
| 风险 | 失效位/熊情景、预计损失、费用与剩余预算 |
| 有效期 | 创建时间、数据时间、到期时间 |
| 证据 | 数据源、复权、算法、模型版本 |

计划完成后复核：批次股数之和不超过目标股数；金额、权重、预计损失、现金和共同暴露一致；最小交易单位和价格 tick 合法；没有声称报单或成交。
