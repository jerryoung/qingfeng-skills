# 组合政策与目标仓位

在输出数值仓位、组合构建或再平衡计划时读取本文件。组合政策先于单笔交易；缺组合净值、现金、持仓和损失承受能力时，只能输出标记为“参考配置”的示例，不声称个人化。

## 一、政策输入

记录并标记来源为 `USER`、`QINGFENG_DEFAULT` 或 `UNKNOWN`：

- 组合净值、现金与最低流动性储备；
- 投资期限、必要回报、最大可承受损失；
- 单标的、行业、地区、币种和共同风险因子上限；
- 核心仓/交易仓偏好、税务、费用、最小交易单位；
- 已有持仓的实际权重、目标权重、未实现风险和资金来源；
- 候选替代项及机会成本。

## 二、清丰均衡配置

用户未提供参数时，可展示以下参考配置，但必须注明 `QINGFENG_DEFAULT · NOT_PERSONALIZED`：

| 约束 | 默认值 |
|---|---:|
| 单标的计划损失占组合净值 | ≤ 1% |
| 初始目标仓位 | ≤ 10% |
| 五闸门全通过后的硬上限 | ≤ 15% |
| 单一行业/共同风险因子 | ≤ 30% |
| 初次试仓占组合净值 | ≤ 2.5% |
| 现金/低风险流动性资产 | ≥ 10% |
| 杠杆、做空、衍生品 | 默认禁用 |

默认值不是适合所有人的答案。缺期限、现金需求或损失承受能力时，组合轴仍为 `UNKNOWN`，交易状态追加 `NO_ACTION`；参考配置只能帮助用户补齐输入。

## 三、目标仓位算法

目标仓位上限取各约束的最小值：

```text
target_weight_cap = min(
  quality_evidence_cap,
  loss_budget_cap,
  single_name_cap,
  factor_remaining_cap,
  liquidity_cap,
  opportunity_cost_cap
)
```

### 损失预算上限

若能定义计划平均成本 `P` 和价格失效位 `S`：

```text
price_loss_fraction = max((P - S) / P, 0) + round_trip_cost_fraction
loss_budget_cap = portfolio_loss_budget_fraction / price_loss_fraction
```

核心仓若没有机械价格止损，改用可解释的熊情景每股价值损失比例 `bear_loss_fraction`，不得编造一个价格失效位：

```text
loss_budget_cap = portfolio_loss_budget_fraction / bear_loss_fraction
```

计算后再应用最小交易单位、现金、费用、流动性和共同暴露约束。使用 [../scripts/trade_plan_calculator.py](../scripts/trade_plan_calculator.py) 计算批次数量时，保留输入 JSON 和输出结果；再用独立表格或手算复核总数量、总金额与预计损失。

### 公司质量上限

- `FAIL`、`UNPROVEN`：0；
- `PASS` 但证据仍有关键缺口：不高于试仓上限；
- 五闸门通过、最强空方已评估：可进入目标仓位计算；
- 治理红线或 `THESIS_BROKEN`：0，并进入退出复核。

### 流动性上限

默认单日计划成交量不超过近 20 个交易日平均成交量的 5%。同时估计正常和压力成交量下的退出天数、价差与滑点；退出需要多个交易日时，下调仓位并披露流动性压力。

## 四、核心仓与交易仓

- **核心仓**：由经营论文、估值和组合预算决定，以 3—5 年经营价值为主要期限；
- **交易仓**：只在核心资格通过后用于分批节奏，由日线趋势、波动和量价决定；
- 技术信号原则上只调整交易仓；核心仓因论文、治理、估值或组合硬约束变化而调整；
- 两部分分别记录目标、实际、成本、资金来源和退出条件，不能混成一笔后再事后解释。

## 五、共同风险与资金来源

目标权重准出前，穿透计算行业、终端客户、供应链、地区/币种、利率、政策、技术路线、估值久期和治理风险。新增仓位必须说明资金来自现金、减少哪项持仓或新增资金，并比较被替代资产的论文强度与预期回报。

不能通过股票数量证明分散；共同风险合计超过政策上限时，组合轴为 `CONSTRAINED`。

## 六、再平衡与换手

满足任一条件才进入再平衡检查：

- 实际权重偏离目标权重超过“目标权重的 20%”或“2 个百分点”中的较大值；
- 单标的或共同风险触及硬上限；
- 论文、赔率、流动性或替代机会发生实质变化；
- 现金低于政策底线。

风险硬上限、治理红线和论文破裂不受容忍带保护。再平衡前估计税费、价差、滑点、换手和机会成本；不为恢复整数权重而交易。
