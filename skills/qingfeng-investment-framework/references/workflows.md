# 青峰工作模式

选择一个主模式。输出深度与用户的问题匹配，不为填满模板扩张研究。

## A. 快速筛选

1. 用一句话说明谁付钱、买什么、如何收费；
2. 检查证券主体、资产归属、数据期间和来源层级；
3. 扫描可得的长期收入、利润、现金、债务、应收存货和股本趋势；
4. 找出最大机制未知、结构性红线和最小补证集；
5. 选择 `OUT_OF_SCOPE` / `REJECT` / `RESEARCH_MORE` / `WATCHLIST`。

完成标准：至少三个继续/停止研究理由，一份最小补证清单，不输出买入结论或伪精确估值。

## B. 深度公司研究

1. 完成能力圈与信息丰富度判断；
2. 构建价值创造链和客户—产品—渠道—交付—经济性—再投资画布；
3. 把核心经营主张逐条写成证伪链；
4. 检查行业利润池、替代品、管理层“承诺—资源—结果—纠错”和治理；
5. 用生存—质量—复利三层财务痕迹验证；
6. 独立建立最强多方和最强空方；
7. 数据准出后完成目标回报门槛、反向估值、三情景和敏感性；
8. 与现金、已有持仓和候选项比较机会成本；
9. 输出五闸门、三轴、总状态和复核规则。

数据不足时允许完成定性熊/基准/牛路径，但不得补造数值目标价。当前价格、完全稀释股本、现金流或价值桥缺失时，赔率轴为 `UNPRICED`，总状态为 `RESEARCH_MORE`。

## C. 估值/重定价

本模式要求近期业务因果与财务验证已准出，否则先补研究。

1. 确认当前价格、市值、完全稀释股本、会计与交易币种；
2. 让用户已给定的必要回报率成为模型主输入；未给定时展示多档门槛，不替用户选唯一值；
3. 用反向模型计算达到各档目标回报需要的业绩；
4. 构建有完整经营故事的熊/基准/牛；
5. 展示年化回报、损失区间、关键敏感性和估值脆弱点；
6. 判断 `ATTRACTIVE` / `FAIR` / `UNFAVORABLE` / `UNPRICED`。

完成标准：不用“低于历史均值”代替目标回报门槛；年化回报已处理分红、回购、稀释和净债务变化。

## D. 买入前检查

买前检查不替代深研。依次闯过生意、证据、复利、赔率、组合五闸门。

必须分别回答：

- 好公司？
- 好价格？
- 适合当前组合？
- 买入理由对应的三个失效条件是什么？
- 更好替代项是什么？

缺完整组合、风险预算、现金需求、税务或流动性信息时，组合轴为 `UNKNOWN`，追加 `NO_ACTION`，不输出数值仓位。

## E. 持仓论文复盘

1. 找到带日期的原始买入论文、估值和失效条件；
2. 先忽略成本价和涨跌，将新事实映射到原论文变量；
3. 标记改善/未变/恶化/未知，并分为噪声/周期/执行偏差/结构性变化；
4. 重算每股价值、目标回报门槛和情景；
5. 分别选择研究总状态和 `HOLD_REVIEW` / `THESIS_DAMAGED` / `THESIS_BROKEN`；
6. 输出下次事件触发器和非执行性条件规则。

原论文不可得时，不事后伪造历史。建立当日“当前基线论文”，总状态设为 `RESEARCH_MORE`，不判断历史论文漂移。

## F. 组合复盘

1. 将每只持仓视为虚拟集团的子公司；
2. 分开计算持股数对应的经营归属值和市值权重对应的风险暴露；
3. 穿透客户、产业链、地区/币种、利率、政策、技术、估值和治理的重复暴露；
4. 建立至少两个与主要暴露匹配的压力情景；
5. 比较论文强度、赔率、下行损失、共同暴露和替代机会；
6. 输出再平衡的触发器，不实施交易。

缺持仓数量/权重、价格、完全稀释股本、现金需求、税务或期限时，只输出定性风险图和待补数据。
