# 清丰策略：从经营到每股价值

## 一、策略目标

清丰策略寻找的不是“最好的公司”，而是在用户期限、必要回报和组合约束下，具备正向不对称赔率的可证伪候选。

优先级顺序：

1. 避免永久性亏损；
2. 确认价值创造机制；
3. 确认现金和每股价值痕迹；
4. 比较再投资与资本配置的机会成本；
5. 用价格获得足够风险补偿；
6. 只在组合边界允许时行动。

## 二、五闸门详解

### 1. 生意闸门

必答：

- 购买者、使用者和付款者是谁；
- 客户要完成什么任务，不购买的代价是什么；
- 替代方案包含竞品、自建、延迟和不消费；
- 公司、渠道、供应商和客户谁控制流量与定价；
- 扩张的最小可复制单元是用户、门店、产能、项目、地区、品类还是 ARPU；
- 什么限制增长：需求、产能、资本、人才、管理、法规或生态利益。

准出标准：能用一条不依赖品牌口号的因果链解释客户价值如何转为股东现金。

### 2. 证据闸门

从业务判断先推导报表痕迹：

| 经营主张 | 应出现的痕迹 | 常见反证 |
|---|---|---|
| 真实定价权 | 量价拆分支持提价，留存/份额稳定 | 促销、返利与流失上升 |
| 结构性复购 | 留存、复购、合同负债与现金匹配 | 获客投入不断上升才维持增长 |
| 规模效应 | 收入快于固定成本，增量利润率改善 | 人力、Capex 和营运资本同比扩张 |
| 高质量利润 | 经营现金与利润长期匹配 | 应收、存货、资本化或一次性项目支撑 |
| 高回报再投资 | 增量 ROIC 稳定，且有可复制空间 | 并购堆规模、回报下降、债务/稀释上升 |

证据强度与独立性分开判断。公司年报可以是历史数字的权威基线，但不能独立证明管理层对未来的预测。

### 3. 复利闸门

将现金的每个去向单独评价：

| 去向 | 核心问题 |
|---|---|
| 内生再投资 | 增量 ROIC 是否高于必要回报，空间有多大？ |
| 研发/长周期 Capex | 哪些是维持性，哪些是增长性？里程碑与回报周期是什么？ |
| 并购 | 剔除并购后的内生增长、商誉和整合结果如何？ |
| 还债 | 降低的融资风险是否高于其他用途？ |
| 分红 | 可分配现金是否可持续，是否损害必要再投资？ |
| 回购 | 回购收益率与内在价值折价是否高于内部项目？ |
| 股权激励/增发 | 总回购后完全稀释股本是否实际下降？ |

先比较机会成本，再评价“战略重要”。管理层把回购资金转向 AI、新产能或并购时，需证明新项目的概率加权回报优于回购或还债，而不是只证明方向重要。

### 4. 赔率闸门

反向问五件事：

1. 当前价格要求收入、利润率、现金流和增长持续多久；
2. 要达到用户必要回报，业绩需要多快增长；
3. 该增长需要多少新增资本，是否会稀释每股价值；
4. 熊情景是“公司不再完美”还是“公司消失”；
5. 与现有持仓、现金和其他候选比较，赔率是否更优。

估值是一组要求与结果，不是单一合理 PE。

### 5. 组合闸门

不用股票数量代替分散。穿透检查：

- 终端客户、产业链、地区和币种；
- 利率、流动性、商品与经济周期；
- 政策、地缘、技术路线、控制人与治理；
- 高久期估值、同一增长叙事和同一资金来源；
- 税务、流动性、时间期限和单一公司损失预算。

缺完整组合信息时，只判断公司与价格，组合轴为 `UNKNOWN`，并追加 `NO_ACTION`。

## 三、行业校准卡

通用流程不等于通用指标。建模前写明：核心价值驱动、资本约束、会计口径、主估值方法和禁用指标。

| 行业形态 | 优先观察 | 主要误区 |
|---|---|---|
| 平台/互联网 | 交易密度、留存、变现率、补贴、监管、生态分配 | 高毛利自动等于强护城河 |
| 消费/零售 | 量价、同店、复购、渠道存货、促销与品牌投入 | 产品熟悉自动等于懂公司 |
| 制造 | 产能利用率、良率、库存、应收、Capex、增量 ROIC | 单期毛利率/周期高点 ROE |
| SaaS | ARR、NRR、RPO、CAC 回收、SBC、现金流 | 用制造业负债率或当期 PE |
| 银行 | 净息差、资产质量、拨备、存款成本、资本充足 | 普通 FCF 或净债务/EBITDA |
| 保险 | 新业务价值、综合成本率、准备金、偿付能力、投资匹配 | 单一 PE 或收入增长 |
| 周期/资源 | 成本曲线、供给纪律、库存、Capex 周期、正常化利润 | 周期高点的低 PE |

## 四、最小可证伪论文

一篇能进入候选池的论文必须压缩成：

1. 客户因什么持续付费；
2. 公司凭什么获得超额回报；
3. 超额回报为什么不会被竞争抹平；
4. 增长需要多少新增资本；
5. 资本配置如何改变完全稀释后的每股价值；
6. 市场当前可能错在哪里；
7. 在用户必要回报下，当前价格需要什么业绩；
8. 哪三个事实会证明自己错了。

无法不依赖口号回答时，论文未闭环。
