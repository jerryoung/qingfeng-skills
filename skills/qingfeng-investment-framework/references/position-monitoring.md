# 持仓跟踪与状态迁移

在持仓建立后、财报/重大事件后或用户要求持续跟踪时读取本文件。跟踪的目标是将原始建仓条件逐条更新，区分事实变化、估值变化、组合变化和短期价格噪声。

## 一、基线与版本

每个持仓维护：

- 论文版本、创建日、数据截止日和证据链接；
- 原目标回报、估值区间、目标/实际权重；
- 核心仓/交易仓数量、成本和资金来源；
- 三个验证指标、三个论文失效条件；
- 技术/筹码只影响执行的条件；
- 计划版本、有效期、触发器状态和处理记录。

原论文不可得时，不事后伪造。建立当日基线，研究状态为 `RESEARCH_MORE`，在准出前不形成新的数值加仓计划。

## 二、三个并行状态

1. 研究状态：`OUT_OF_SCOPE` / `REJECT` / `RESEARCH_MORE` / `WATCHLIST` / `CANDIDATE`；
2. 论文状态：`HOLD_REVIEW` / `THESIS_DAMAGED` / `THESIS_BROKEN`；
3. 计划状态：`OBSERVE` / `READY` / `BUILDING` / `HELD` / `PAUSE_ADD` / `REVIEW` / `TACTICAL_REDUCE` / `STRATEGIC_REDUCE` / `EXIT`。

三者分别记录，不因价格上涨把论文状态升级，也不因技术破位把论文伪装成破裂。

## 三、跟踪频率

| 频率 | 检查内容 |
|---|---|
| 每周 | 价格、周/日趋势、波动、量价、执行数据时效和权重漂移 |
| 每月 | 共同风险、流动性、候选机会成本、目标/实际权重与现金底线 |
| 财报后 | 重跑生意、证据、复利、估值和每股价值桥 |
| 事件触发 | 业绩预告、管理层/治理、监管、重大资本配置、竞争格局和公司行动 |
| 红线触发 | 立即冻结新增计划并进入人工复核 |

默认只输出跟踪清单和下次复核日期。仅在用户明确要求持续监控时创建只读提醒；提醒可更新证据与建议，不能自动交易。

## 四、触发器账本

| 触发器 | 原始阈值/条件 | 当前证据 | 状态 | 影响层 | 计划动作 | 处理结果 |
|---|---|---|---|---|---|---|
|  |  |  | 未触发/预警/已触发/已处理 | 论文/估值/组合/执行 |  |  |

每次变化写入版本日志：时间、旧值、新值、来源、判断、行动资格、计划版本和下次证据。动作完成后必须回写实际权重和剩余风险预算；无法验证实际成交时保持“待用户确认”。

## 五、状态迁移

```text
OBSERVE
→ READY
→ BUILDING
→ HELD
→ PAUSE_ADD
→ REVIEW
→ TACTICAL_REDUCE / STRATEGIC_REDUCE
→ EXIT
```

允许从任一行动状态返回 `REVIEW`。只有重新满足公司、赔率、组合和数据准出，才可返回 `READY` 或 `BUILDING`。

状态迁移至少记录：触发事实、对应原始条件、最强其他解释、影响的三轴/论文状态、动作范围、取消条件和下次复核。

## 六、动作矩阵

| 变化 | 论文状态 | 计划状态 | 默认动作 |
|---|---|---|---|
| 经营证据改善且赔率仍好 | `HOLD_REVIEW` | `READY/BUILDING` | 允许检查下一批，不自动加仓 |
| 仅价格上涨、论文未变 | 不变 | `HELD/PAUSE_ADD` | 重算回报，不因盈利升级论文 |
| 仅技术走弱 | 不变 | `PAUSE_ADD/TACTICAL_REDUCE` | 暂停加仓；只调整交易仓 |
| 论文受损、待补证 | `THESIS_DAMAGED` | `STRATEGIC_REDUCE` | 参考减至原目标仓位 50%，等待用户确认 |
| 论文破裂/治理红线 | `THESIS_BROKEN` | `EXIT` | 取消全部待买计划，形成退出草案 |
| 估值回报低于门槛 | 不一定改变 | `STRATEGIC_REDUCE` | 先减交易仓，再重算核心目标 |
| 组合硬约束超限 | 不一定改变 | `STRATEGIC_REDUCE` | 按论文、赔率、暴露和流动性排序 |
| 数据过期或冲突 | `RESEARCH_MORE` | `REVIEW` | 冻结数值计划，补数据 |

建仓和减仓不是机械镜像：价格离开买入区、技术确认消失或成本价被跌破，不自动构成核心仓卖出理由。

## 七、异常闭环

- 向上跳空：暂停未成交买入，不追价；
- 向下跳空：先判断事件与论文，不机械补仓；
- 停牌/涨跌停：冻结计划，不声称可执行；
- 部分成交：只有获得可验证实际数量后才更新组合；
- 分红、拆股、配股：重算历史价格、持股数、成本、权重和触发位；
- 计划到期：状态回到 `REVIEW`，不得沿用旧区间。

## 八、组合跟踪面板

| 标的 | 研究/论文/计划状态 | 目标/实际权重 | 核心/交易仓 | 预计损失 | 共同风险 | 下一触发器 | 计划到期 |
|---|---|---:|---|---:|---|---|---|
|  |  |  |  |  |  |  |  |

组合层再记录现金、共同风险余额、税费/换手、本期实际动作、未处理预警和机会成本排序。没有完整数据时保持 `UNKNOWN + NO_ACTION`。
