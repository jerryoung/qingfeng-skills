# 技术与筹码执行分析

本模块只回答“何时、分几次”，不回答“公司是否合格、价格是否有价值”。技术或筹码信息不得把基本面、估值或组合未准出的标的变成可买。

## 一、数据准出

计算前记录：证券代码、交易所、时区、数据源、截止时间、频率、复权方式、币种、停复牌、公司行动和缺失区间。

必须满足：

- OHLCV 覆盖所需窗口，最新数据未超过计划允许时效；
- 历史分析使用一致复权序列，公司行动前后可以桥接；
- 当前计划价格使用真实交易口径，价格 tick 与最小交易单位合法；
- 成交量、自由流通股和换手口径可解释；
- 空值、停牌和异常成交不填成 0。

任一关键项失败时，执行分析标记 `UNSUPPORTED`，不计算价格带或数值批次。

## 二、周期分工

- **季度/事件**：验证经营论文和估值；
- **周线**：判断核心趋势、长期支撑与相对强弱；
- **日线**：确定试仓、确认、完成与战术减仓节奏；
- **分钟级**：不属于本 Skill。

核心仓以 3—5 年经营价值为主要期限；日线噪声不能单独推翻核心论文。

## 三、最小技术集合

只使用能提供不同信息的四组变量：

1. **趋势状态**：价格相对中长期趋势线、趋势斜率与高低点结构；
2. **波动水平**：ATR 或等价真实波动，用于价格带、计划失效和头寸风险；
3. **量价结构**：突破、回踩、放量、缩量、承接与抛压；
4. **相对强弱**：相对行业、宽基指数和候选替代项。

MACD、RSI 可作辅助描述，不与上述变量重复计票；KDJ、波浪计数和主观形态不作为强制准出条件。输出每个信号的周期、公式/参数、当前值、历史区间、其他解释和失效条件，不使用“多指标共振”掩盖重复信息。

## 四、价格区域

从估值模块取得最高可接受价格 `P_max` 后，再识别：

- 观察区：赔率尚未满足或技术结构不支持行动；
- 试仓区：低于 `P_max`，波动可承受，允许小额验证；
- 确认区：仍低于 `P_max`，经营证据或量价结构改善；
- 完成区：论文、赔率、组合额度与执行结构全部仍成立；
- 暂停区：下跌原因未知、波动异常、数据过期或组合受限；
- 失效区：论文/治理红线、估值要求、风险预算或交易仓结构位被破坏。

ATR 和支撑阻力用于形成区间，不输出伪精确单点。参数应与用户期限和标的波动匹配，未做历史检验时不声称“最优”。

## 五、筹码信息分级

| 等级 | 内容 | 可用方式 |
|---|---|---|
| A 正式披露 | 股东名册、机构/高管增减持、回购、限售解禁、可靠托管或持仓统计 | 可支持供给变化与治理判断，仍有披露时滞 |
| B 可复算估计 | 基于复权价格和成交量的成交量分布、锚定 VWAP 等 | 只称“成交成本分布估计”，用于候选支撑/压力区 |
| C 供应商推算 | 数据商筹码峰、获利盘和成本分布算法 | 标记来源、算法、日期与置信度，仅辅助执行 |
| U 不支持 | 来源或算法不可解释、市场口径不适用、数据过期 | `UNSUPPORTED`，不得参与行动 |

成交量分布不是实际股东持仓成本。历史成交无法确认筹码是否仍由同一投资者持有。A 股之外默认不使用 A 股式筹码峰；港股、美股只在市场和数据口径得到解释时启用相应信息。

## 六、筹码计算边界

若计算成交量分布：

- 说明窗口、价格分桶、成交量在当日区间内的分配假设；
- 处理复权、自由流通股变化、拆股、配股和异常成交；
- 做窗口、分桶和衰减假设的敏感性；
- 不把估计峰值写成“主力真实成本”；
- 不让单一筹码区覆盖估值上限或基本面失效条件。

## 七、冲突裁决

| 冲突 | 裁决 |
|---|---|
| 基本面失败 + 技术走强 | 不建仓，状态按基本面失败 |
| 估值未准出 + 筹码集中 | 不建仓，补估值与证据 |
| 估值有吸引力 + 趋势恶化 | 观察或小额试仓，解释下跌后再加 |
| 核心论文未变 + 技术破位 | 暂停加仓或调交易仓，不伪称论文破裂 |
| 论文破裂 + 价格更低 | 取消补仓，进入退出复核 |
| 技术支撑高于估值上限 | 服从估值，不追价 |

## 八、输出卡

- 数据准出：`SUPPORTED` / `LIMITED` / `UNSUPPORTED`；
- 周线趋势、日线执行状态、ATR/波动、量价与相对强弱；
- 筹码等级、来源、算法、窗口、复权与置信度；
- 候选价格区间及与 `P_max` 的关系；
- 支持行动的证据、其他解释和失效条件；
- 本模块只影响哪一批交易仓；
- 数据到期和重新计算触发器。
