# 论文、组合与复盘

## 一、带日期的论文卡

每个候选或持仓维护：

| 字段 | 内容 |
|---|---|
| 数据日 | 研究日、数据截止日和未核验范围 |
| 一句话生意 | 谁付钱、买什么、如何收费 |
| 价值创造链 | 从客户价值到每股价值 |
| 核心优势 | 超额回报的机制和持续条件 |
| 资本配置 | 再投资、并购、还债、分红、回购、稀释的机会成本 |
| 市场可能错在哪里 | 与当前定价不同的可验证判断 |
| 最强空方 | 公司不消失仍可导致低回报的路径 |
| 三个验证指标 | 能持续支持论文的领先/滞后痕迹 |
| 三个失效条件 | 明确证伪核心论文的事实 |
| 赔率 | 用户必要回报、熊/基准/牛与脆弱点 |
| 三轴与总状态 | 公司质量、价格赔率、组合适配与总状态 |
| 下次复核 | 日期或事件触发器 |

“市场可能错在哪里”无法回答时，承认没有可识别的认知差；不用“好公司”自动补上。

## 二、持仓复盘

先读原论文，再看新事实。价格和持仓盈亏不是论文变量。

| 论文变量 | 原假设 | 新事实 | 变化 | 每股价值影响 | 下一证据 |
|---|---|---|---|---|---|
| 客户需求/留存 |  |  | 改善/未变/恶化/未知 |  |  |
| 定价/份额 |  |  |  |  |  |
| 单位经济/利润率 |  |  |  |  |  |
| 现金/再投资 |  |  |  |  |  |
| 竞争优势 |  |  |  |  |  |
| 资本配置/稀释 |  |  |  |  |  |
| 治理/监管 |  |  |  |  |  |
| 目标回报门槛 |  |  |  |  |  |

变化类型：

- **噪声**：不改变中长期每股现金流；
- **周期**：可逆，需要正常化；
- **执行偏差**：机制仍可成立，但时间/成本超出原假设；
- **结构性变化**：需求、优势、资本回报或治理永久改变。

持仓论文状态：

- `HOLD_REVIEW`：核心必要条件仍受支持；
- `THESIS_DAMAGED`：核心假设已受实质反证，但不可替代的必要条件未完全破裂；
- `THESIS_BROKEN`：任一不可替代必要条件或治理红线被证伪。

买入因为定价权，就用量价、份额、促销和毛利判断退出；买入因为高回报再投资，就用增量 ROIC、里程碑和每股价值判断。买卖使用同一组变量。

## 三、虚拟集团的两种口径

### 经营归属值

```text
公司指标 × 投资者持股数 ÷ 公司完全稀释股本
```

在行业口径可比时汇总归属收入、利润、FCF/可分配利润、净债务/资本约束、分红、回购和稀释。银行、保险和一般企业分组展示，不机械相加。

### 风险暴露值

```text
公司风险指标 × 该持仓组合市值权重
```

穿透：终端客户、产业链、地区/币种、利率/流动性、商品、政策/地缘、技术路线、估值风格和治理。

组合的目标不是拥有足够多股票，而是没有不自知的共同单点失效。

## 四、压力情景与机会成本

每次组合复盘至少建立两个与主要暴露匹配的情景：

1. 定义冲击、强度和持续期；
2. 写清收入、利润率、现金、融资和估值的一阶/二阶传导；
3. 估计组合损失区间和流动性/被迫卖出风险；
4. 比较每个持仓的论文强度、情景年化回报、共同暴露和替代项；
5. 预设再平衡或暂停行动的触发器。

缺完整持仓、权重、价格、完全稀释股本、现金需求、税务、期限或流动性信息时，组合轴为 `UNKNOWN`，只输出定性风险图和待补数据。

## 五、年度归因

将总回报拆分为：

- 企业每股经营增长；
- 分红与净回购；
- 股权稀释；
- 净债务/资本结构变化；
- 估值扩张或收缩；
- 仓位和标的选择；
- 交易成本、税费与错误损失。

区分哪些回报来自原论文，哪些来自意外的估值变化或运气。数据不全时不声称已验证超额能力。
