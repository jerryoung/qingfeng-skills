# 清丰投资策略

> **经营是因，报表是痕，价格是赔率，组合是边界，复盘是证伪。**

本 Skill 用“五道闸门、两条链、三轴判决和一套人工确认型交易计划”把公司研究连接到组合管理。目标是找到“看得懂、现金真、能复利、赔率好、组合容得下”的候选，并在证据充分时形成可计算、可取消、可复盘的计划，而不是拼凑买入理由或预测最佳点位。

方法来源与清丰自主规则见 [provenance.md](references/provenance.md)。需要对外说明参考内容、输出完整报告或解释规则来源时，必须读取该文件。

## 选择一个主模式

| 用户问题 | 主模式 | 完成状态 |
|---|---|---|
| “值不值得继续研究” | 快速筛选 | 研究优先级与最小补证清单 |
| “深度分析某公司” | 深度公司研究 | 因果模型、证据链、估值与反方论文 |
| “现在这个价格怎么看” | 估值/重定价 | 目标回报门槛、情景赔率与脆弱点 |
| “准备买入” | 买入前检查 | 五闸门准出、三轴判决与行动资格 |
| “组合怎么配置” | 组合政策/构建 | 目标权重、损失预算、共同暴露与资金来源 |
| “分几次、什么位置买卖” | 交易计划 | 价格带、批次、仓位、触发器、有效期与取消条件 |
| “财报后/大跌后还能不能拿” | 持仓跟踪 | 论文状态、计划状态、加减仓与退出条件 |
| “组合是否集中/分散” | 组合复盘 | 共同风险、机会成本、压力情景与再平衡条件 |

开始后阅读 [workflows.md](references/workflows.md) 中对应模式，只执行一条主流程：

- 深研、估值和买前检查同时读取 [evidence-and-valuation.md](references/evidence-and-valuation.md)；
- 组合构建或数值仓位读取 [portfolio-policy.md](references/portfolio-policy.md)；
- 建仓、加仓、减仓或退出计划读取 [trade-plan.md](references/trade-plan.md)；
- 使用技术或筹码信息读取 [technical-and-chip-analysis.md](references/technical-and-chip-analysis.md)；
- 持仓、触发器或持续跟踪读取 [position-monitoring.md](references/position-monitoring.md) 和 [portfolio-and-review.md](references/portfolio-and-review.md)。

## 统一输入卡

先写清：

- 公司、证券代码、上市地、主要经营实体；
- 研究日、数据截止日、币种、单位、报告期与是否审计；
- 用户期限、目标回报、流动性、最大可承受损失和现金需求；
- 组合净值、现金、已有持仓、目标/实际权重、候选替代项和共同风险；
- 核心仓/交易仓偏好、允许市场、费用税率、最小交易单位；
- 允许的数据源、已知限制，以及会改变结论的缺口。

当前价格、复权行情、成交量、股本、财报、管理层、政策和行业格局属于易变事实，必须用当前可用的合规金融数据或一手披露刷新。无法刷新时标记“未做当前核验”：估值不准出，交易计划为 `NO_ACTION`，不用训练记忆补数。

## 决策层级

```text
结构性论文与治理红线
> 组合硬约束
> 估值赔率
> 技术与筹码执行节奏
```

- 基本面决定能否持有；
- 估值决定是否值得买；
- 组合风险决定最多买多少；
- 技术与筹码只决定何时、分几次执行。

技术或筹码不能把 `FAIL`、`UNPROVEN`、`UNPRICED` 或 `CONSTRAINED` 提升为可买。每一批加仓前重新检查论文、赔率、组合额度和数据时效。

## 两条必经链

### 价值创造链

```text
客户任务与付费理由
→ 产品/服务与替代方案
→ 获客、交付、定价和复购
→ 单位经济与利润池
→ 自由现金流/可分配利润
→ 再投资、并购、还债、分红、回购与稀释
→ 每股价值增长
```

### 证伪链

```text
经营主张
→ 作用机制
→ 若为真应出现的财务/经营痕迹
→ 当前证据
→ 最强反证或其他解释
→ 明确失效条件
```

核心论断没有走完两条链，保留为 `未知`，不进入估值与数值交易计划。

## 五道准出闸门

1. **生意闸门**：能解释谁付钱、为何付钱、替代是什么、谁控制渠道与利润池。
2. **证据闸门**：关键主张有一手基线、独立交叉验证和可解释的财务痕迹。
3. **复利闸门**：增量资本回报、再投资空间和资本配置优于机会成本，总量增长能到达每股价值。
4. **赔率闸门**：价格隐含要求可达，用户必要回报下的熊情景损失可承受、基准情景有吸引力。
5. **组合闸门**：共同风险、流动性、税务、损失预算和替代项允许行动。

前一道关键闸门未通过时，后一道不得用更好的叙事、更低的价格或技术信号补偿。具体画布与行业校准见 [strategy.md](references/strategy.md)。

## 三轴判决与总状态

结论必须同时报告三轴，不将它们压成“买/卖”：

| 判决轴 | 可用状态 |
|---|---|
| 公司质量 | `UNPROVEN` / `PASS` / `FAIL` |
| 价格赔率 | `UNPRICED` / `ATTRACTIVE` / `FAIR` / `UNFAVORABLE` |
| 组合适配 | `UNKNOWN` / `FIT` / `CONSTRAINED` |

再按失败原因生成总状态：

- 能力圈无法建立：`OUT_OF_SCOPE`；
- 生意、生存、治理或论文出现结构性红线：`REJECT`；
- 可补的关键证据缺失/冲突，或估值未准出：`RESEARCH_MORE`；
- 公司质量通过，但赔率或事件触发器未满足：`WATCHLIST`；
- 生意、证据、复利和赔率均准出：`CANDIDATE`；
- 组合信息不足或受约束：在主状态后追加 `NO_ACTION`。

持仓另行报告 `HOLD_REVIEW` / `THESIS_DAMAGED` / `THESIS_BROKEN`；计划另行报告 `OBSERVE` / `READY` / `BUILDING` / `HELD` / `PAUSE_ADD` / `REVIEW` / `TACTICAL_REDUCE` / `STRATEGIC_REDUCE` / `EXIT`。研究状态、论文状态和计划状态不得互相覆盖。

## 估值、仓位与交易计划约束

- 先反向估值，再正向估值；先设必要回报，再计算业绩与最高可接受价格；
- 熊/基准/牛各有完整经营故事，历史和同业倍数只作交叉检查；
- 仓位上限取公司质量、损失预算、单股/共同因子、流动性和机会成本约束中的最小值；
- 默认风险参数仅形成标记为“参考配置”的清丰均衡方案；缺个人组合信息不声称个性化；
- 估值给价格天花板，波动给区间宽度，支撑/成交分布给候选区，趋势/量价给批次顺序；
- 默认试仓/确认仓/完成仓为目标仓位的 25%/35%/40%，未满足前提的批次保留而非机械成交；
- 计划默认有效 5 个交易日；公告、跳空、复权、波动、论文、估值或组合变化会提前作废；
- 输出 `DRAFT`、`REQUIRES_USER_APPROVAL` 的非执行 Order Intent，不输出“最佳买点”或成交声称。

公式、证据准出见 [evidence-and-valuation.md](references/evidence-and-valuation.md)；仓位、技术筹码、交易与跟踪细则按上述路由读取。影响结论的计算使用可复现工具，保留输入、公式、单位和第二种复核。

## 交付契约

所有模式至少输出：

1. 模式、数据截止日、数据版本和未核验范围；
2. 一句话结论、三轴判决与总状态；
3. 价值创造链和至少一条完整证伪链；
4. 五闸门判决及未通过原因；
5. 最强多方、最强空方和会改变结论的未知；
6. 三个验证指标、三个失效条件和下次复核触发器；
7. 数据源、口径冲突、计算、费用和参考方法备注；
8. “好公司、好价格、适合当前组合”的独立结论。

涉及仓位或交易时再输出：组合政策来源、目标/实际权重、资金来源、核心/交易仓、每批价格带与数量、触发/取消条件、计划有效期、预计费用与损失、剩余风险预算，以及 `DRAFT · REQUIRES_USER_APPROVAL · NOT_AN_ORDER`。

用户要求文件时，公司研究使用 [company-research-template.md](assets/company-research-template.md)，组合政策使用 [portfolio-policy-template.md](assets/portfolio-policy-template.md)，交易计划使用 [trade-plan-template.md](assets/trade-plan-template.md)，持仓跟踪使用 [position-monitor-template.md](assets/position-monitor-template.md)，论文和组合复盘继续使用原模板。默认在对话中交付，不擅自创建报告。

## 非执行边界

本 Skill 只做研究与人工审批前支持：

- 不调用券商、QMT 或下单接口；
- 不保存、回显或传播账户凭证；
- 不声称已报单、已成交、正在重试或正在监控，除非产品确实创建了用户明确要求的只读提醒；
- 跳空、停牌、涨跌停、部分成交或计划失效时只重算状态，不盲目重试；
- 真实交易只由用户或获授权的确定性执行系统完成。

## 完成前闸门

- 因果顺序为经营 → 财务 → 估值 → 组合 → 执行节奏；
- 每个核心主张有证据、反证/未知和失效条件；
- 总量增长已桥接至完全稀释每股价值；
- 估值包含必要回报、反向门槛、三情景、敏感性和年化回报；
- 公司、价格、组合三轴独立，任一关键轴未准出时不生成可行动计划；
- 仓位数学满足损失预算、权重上限、共同暴露、现金、流动性、费用和最小交易单位；
- 技术/筹码数据有周期、复权、来源、时间戳和可信度，且没有越级推翻基本面或估值；
- 建仓与减仓非机械对称，每次状态迁移都有原因、动作和复核闭环；
- 计划标明有效期、取消/重算条件和非订单状态；
- 参考内容已备注，没有把清丰改造写成他人原话；
- 没有越权下单。

关键项未通过时，按失败原因选择研究、论文和计划状态，说明差距后收口。
