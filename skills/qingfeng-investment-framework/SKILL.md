# 青峰投资策略

> **经营是因，报表是痕，价格是赔率，组合是边界，复盘是证伪。**

本 Skill 用“五道闸门、两条链、三轴判决”把公司研究变成可证伪、可计算、可复盘的决策流程。目标是找到“看得懂、现金真、能复利、赔率好、组合容得下”的候选，而不是为任何公司拼凑买入理由。

方法来源与青峰自主改造的边界见 [provenance.md](references/provenance.md)。需要对外说明参考内容、输出完整报告或解释某条规则来源时，必须读取该文件。

## 选择一个主模式

| 用户问题 | 主模式 | 完成状态 |
|---|---|---|
| “值不值得继续研究” | 快速筛选 | 研究优先级与最小补证清单 |
| “深度分析某公司” | 深度公司研究 | 因果模型、证据链、估值与反方论文 |
| “现在这个价格怎么看” | 估值/重定价 | 目标回报门槛、情景赔率与脆弱点 |
| “准备买入” | 买入前检查 | 五闸门准出、三轴判决与组合行动闸门 |
| “财报后/大跌后还能不能拿” | 持仓论文复盘 | 原论文改善、受损或破裂的证据 |
| “组合是否集中/分散” | 组合复盘 | 共同风险、机会成本和压力情景 |

开始后阅读 [workflows.md](references/workflows.md) 中对应的模式，只执行那一条主流程。深研、估值和买前检查同时阅读 [evidence-and-valuation.md](references/evidence-and-valuation.md)；持仓或组合任务阅读 [portfolio-and-review.md](references/portfolio-and-review.md)。

## 统一输入卡

先写清：

- 公司、证券代码、上市地、主要经营实体；
- 研究日、数据截止日、币种、单位、报告期与是否审计；
- 用户期限、目标回报、流动性和最大可承受损失；
- 已有持仓、候选替代项和共同风险暴露（若适用）；
- 允许的数据源、已知限制，以及会改变结论的缺口。

当前价格、财报、股本、管理层、政策和行业格局属于易变事实，必须用当前可用的合规金融数据或一手披露刷新。无法刷新时标记“未做当前核验”，估值不准出，不用训练记忆补数。

## 两条必经链

### 价值创造链

```text
客户任务与付费理由
→ 产品/服务与替代方案
→ 获客、交付、定价和复购
→ 单位经济与利润池
→ 自由现金流/可分配利润
→ 再投资、并购、还债、分红、回购与稀释
→ 每股价值增长
```

### 证伪链

```text
经营主张
→ 作用机制
→ 若为真应出现的财务/经营痕迹
→ 当前证据
→ 最强反证或其他解释
→ 明确失效条件
```

核心论断没有走完两条链，保留为 `未知`，不进入估值模型。

## 五道准出闸门

1. **生意闸门**：能解释谁付钱、为何付钱、替代是什么、谁控制渠道与利润池。
2. **证据闸门**：关键主张有一手基线、独立交叉验证和可解释的财务痕迹。
3. **复利闸门**：增量资本回报、再投资空间和资本配置优于可比机会成本，总量增长能到达普通股的每股价值。
4. **赔率闸门**：当前价格隐含的经营要求可达，且在用户必要回报率下熊情景损失可承受、基准情景有吸引力。
5. **组合闸门**：标的的共同风险、流动性、税务、损失预算和替代项允许行动。

前一道关键闸门未通过时，后一道不得用更好的叙事或更低的价格补偿。具体画布与行业校准见 [strategy.md](references/strategy.md)。

## 三轴判决与总状态

结论必须同时报告三轴，不将它们压成“买/卖”：

| 判决轴 | 可用状态 |
|---|---|
| 公司质量 | `UNPROVEN` / `PASS` / `FAIL` |
| 价格赔率 | `UNPRICED` / `ATTRACTIVE` / `FAIR` / `UNFAVORABLE` |
| 组合适配 | `UNKNOWN` / `FIT` / `CONSTRAINED` |

再按失败原因生成总状态：

- 能力圈无法建立：`OUT_OF_SCOPE`；
- 生意、生存、治理或论文出现结构性红线：`REJECT`；
- 可补的关键证据缺失/冲突，或估值未准出：`RESEARCH_MORE`；
- 公司质量通过，但赔率或事件触发器未满足：`WATCHLIST`；
- 生意、证据、复利和赔率均准出：`CANDIDATE`；
- 组合信息不足或受约束：在主状态后追加 `NO_ACTION`。

持仓复盘另行报告 `HOLD_REVIEW` / `THESIS_DAMAGED` / `THESIS_BROKEN`，不覆盖上述研究状态。

## 估值的青峰约束

- 先反向估值，再正向估值；
- 先设定用户必要回报，再计算业绩门槛；
- 熊/基准/牛情景必须各自有完整经营故事，不只换倍数；
- 历史估值和同业倍数只作交叉检查；
- 处理净债务、投资资产、少数股东、或有义务、股权激励、回购与完全稀释股本；
- 输出情景年化回报和脆弱性，不只输出目标价涨幅。

精确公式、证据账本和准出规则见 [evidence-and-valuation.md](references/evidence-and-valuation.md)。所有影响结论的计算使用可复现工具并保留输入、公式、单位和第二种复核。

## 交付契约

所有模式至少输出：

1. 模式、数据截止日和未核验范围；
2. 一句话结论、三轴判决与总状态；
3. 价值创造链和至少一条完整证伪链；
4. 五闸门判决，其中未通过项需写明原因；
5. 最强多方、最强空方和会改变结论的未知；
6. 三个验证指标、三个失效条件、下次复核触发器；
7. 数据源、口径冲突、计算和参考方法的备注；
8. “好公司、好价格、适合当前组合”的独立结论。

用户明确要求文件时，公司研究使用 [company-research-template.md](assets/company-research-template.md)，持仓复盘使用 [thesis-review-template.md](assets/thesis-review-template.md)，组合复盘使用 [portfolio-review-template.md](assets/portfolio-review-template.md)。默认在对话中交付，不擅自创建报告。

## 非执行边界

本 Skill 只做研究和人工决策前支持：

- 不调用券商、QMT 或下单接口；
- 不保存、回显或传播账户凭证；
- 不声称已报单、已成交或正在重试；
- 可输出风险预算、暴露上限、分批条件或非执行性 Order Intent 草案；
- 真实交易只由用户或获授权的确定性系统执行。

## 完成前闸门

- 因果顺序是经营 → 财务 → 估值，不是价格 → 故事；
- 每个核心主张有证据、反证/未知和失效条件；
- 证据强度、数据时效与结论强度一致；
- 总量增长已桥接至每股价值，已检查股权激励、回购与稀释；
- 估值包含用户必要回报、反向门槛、三情景、敏感性和年化回报；
- 三轴判决独立，组合信息不足时追加 `NO_ACTION`；
- 最强空方能够在不要求公司消失的情况下解释估值为何会下降；
- 参考内容已备注，没有把青峰改造写成他人原话；
- 没有越权下单。

关键项未通过时，按失败原因选择 `OUT_OF_SCOPE`、`REJECT`、`RESEARCH_MORE`、`WATCHLIST` 或追加 `NO_ACTION`，说明差距后收口。
