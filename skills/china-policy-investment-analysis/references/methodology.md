# 纵向比较方法

用于多期五年规划、中央《建议》、起草说明或同类中国政策文本的结构与关键词分析。

## 1. 证据登记表

每份材料至少登记：

| 字段 | 说明 |
|---|---|
| `period` | 政策期或规划期 |
| `title` | 文件完整标题 |
| `document_type` | 建议、说明、纲要、专项规划、预算、项目清单等 |
| `authority` | 批准机关、发布机关或转载机关 |
| `published_at` | 成文或发布日期；两者都有时分别保留 |
| `status` | 征求意见、正式发布、人大批准、预算授权、资金下达等 |
| `source` | 官方 URL 或本地文件绝对路径 |
| `sha256` | 本地文件哈希；网页记录抓取日期 |
| `body_rule` | 正文起止、是否排除目录、是否含标题/专栏/附表 |
| `extraction` | 原生文本、PDF 提取、OCR 或人工转录 |

证据优先级：批准机关正式文本 > 发布机关正式文本 > 部委/政府授权转载 > 原始公司或项目公告 > 权威媒体实录 > 二手研究。后两级适合发现线索，不承担关键结论的唯一证据。

## 2. 结构编码

先建立“时期 × 主题”的矩阵，再写叙述。

| 编码 | 判定 |
|---|---|
| 连续 | 主题跨期存在，层级和功能基本稳定 |
| 升格/降格 | 章升为篇，或篇降为章/节 |
| 前移/后移 | 同级结构中的位次明显变化 |
| 拆分/合并 | 一个主题变为多个独立单元，或多个主题进入一个综合框架 |
| 新增 | 前期无对应任务，本期出现独立结构或明确机制 |
| 任务转型 | 名称弱化或退出，但任务由攻坚转为常态治理、衔接或存量管理 |
| 退出 | 原任务及可识别承接机制均未出现；必须给出检索证据 |

结构结论必须回答三件事：它放在哪里、相邻主题是什么、正文要求政府或市场做什么。

## 3. 关键词口径

推荐口径：

1. 对 Unicode 做 NFKC 归一化；
2. 删除词内跨行空白后做精确子串计数；
3. 同时报告次数和 `次数 / 正文汉字数 × 10000`；
4. 保留关键词原形，不默认合并近义词；需要概念簇时另建词表并逐项披露；
5. 标题、目录、正文、专栏和附表的纳入规则保持跨期一致；
6. 抽样回看每个高信号词在标题、目标、工程、监管和普通描述中的语境。

词频变化的可靠写法是“提示结构变化，正文与篇章位置进一步支持”；不可靠写法是“出现次数增加，所以政策重要性按同样比例增加”。

## 4. PDF 与版本陷阱

- 同名文件可能是征求意见稿、建议稿、批准稿或后续排版稿；先比标题页、批准日期和哈希。
- 目录会复制标题，未排除时会把结构词频算两次。
- 旧 PDF 可能视觉正常但文本层错乱，或文本可抽取但字体渲染异常；至少用两种方法抽查关键页。
- OCR 会把中文数字、百分号和专有名词识错；所有结构数量与关键数字回看页面。
- 字幕、视频与评论只提供方法线索；其计数必须在正式文本上重新执行。

## 5. 人物姓名分析（仅在用户明确要求时）

统计正文次数之外，按出现位置编码：指导思想、历史回顾、专业领域、实施保障或结尾。把“现任/历任”“总论/专业篇”“引用谱系/具体任务”分开。

只支持文本层结论。姓名次数或位置不能单独推出权力强弱、个人动机、组织运行、执行效果或社会舆论。

公开发布需要脱敏时，不在此分析中直接改写证据；先完成内部证据表，再按 [公开发布与脱敏](publication.md) 生成独立公开版本。

## 6. 最小可复现记录

交付物中保留：研究日期、文件清单、哈希或官方链接、提取方法、统计命令、正文边界、关键词表、异常文件与人工复核结果。无法复现的精确次数降级为定性描述。
