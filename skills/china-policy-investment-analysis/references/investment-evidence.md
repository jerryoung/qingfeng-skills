# 投资证据链

仅在用户要求行业、公司、估值、组合或投资结论时读取。

## 1. 从政策到现金流的状态机

按以下顺序记录证据，不跳级：

> 方向性表述 → 正式规划任务 → 年度预算授权 → 资金分配/项目清单 → 拨付 → 开工 → 招标/中标 → 公司订单 → 收入确认 → 经营现金流

每一层回答：来源、发布日期、文件状态、金额口径、覆盖范围、下一层尚缺什么。财政总盘子不能整体映射为产业需求；基金目标规模不能写成已实缴；意向项目不能写成已投资。

## 2. 政策工具映射

| 工具 | 更接近的经济含义 | 常见误读 |
|---|---|---|
| 一般公共预算 | 公共支出总盘子 | 全部视为产业投资 |
| 中央预算内投资 | 政府投资与对地方转移 | 预算等于企业订单 |
| 特别国债 | 指定重大任务的长期资金 | 所有金额可直接相加 |
| 地方专项债 | 项目建设、化债、清欠等 | 总限额全部算新增基建 |
| 政策性金融工具 | 项目资本金或融资支持 | 当作财政无偿支出 |
| 政府投资基金 | 长期股权资本和社会资本引导 | 目标规模当作实缴规模 |
| 标准、准入和监管 | 改变竞争门槛与成本 | 只有补贴才算政策支持 |

## 3. 产业链验证

为每条主线画出上游—中游—下游—付费方，至少跟踪：

- 需求：销量、订单、招标、渗透率、客户资本开支；
- 供给：产能、开工率、竞争者数量、扩产计划；
- 价格与库存：产品价格、原材料价格、渠道/企业库存；
- 利润：毛利率、净利率、资本回报率、自由现金流；
- 传导：谁先受益，谁承担降价，价值是否转向设备、控制、运维、标准或软件。

“产量增长 + 价格下降”通常说明需求真实但利润可能被供给竞争吞噬。把长期文明趋势与当期股东回报分开。

## 4. 公司观察池

公司进入观察池前至少回答：

1. 收入中有多少真正暴露于政策方向，口径来自哪个报告期；
2. 客户为何选择它，认证、良率、服务、数据、渠道或成本优势能否持续；
3. 收入、归母利润、经营现金流、毛利率、ROE 和资产负债率是否同向；
4. 应收、合同资产、存货和资本化研发是否快于收入；
5. 当前 PE/PB/PS/EV-EBITDA 使用哪个最合适，市场已包含什么增长预期；
6. 当前估值处于自身历史和同业什么位置；
7. 哪个季度、价格、技术或政策事件最先证伪逻辑。

关键财务数据优先以公司原始定期报告核对结构化数据。两来源误差超过 1% 时列出两个值和口径；超过 5% 时回到原始报表，不直接使用。

## 5. 最新数据规则

- 先运行 `date`，行情使用最近交易日，财务使用最新已披露报告期；
- 报告发布日期晚于研究日的数据不得使用；
- `null` 表示缺失，不当作 0；尚未披露不使用预测值填空；
- 币种、复权、总市值、TTM/LYR 和会计口径必须显式标注；
- 发现单位冲突时停止横向比较，保留异常并转查原始披露。

## 6. 排序与组合

分别给出：

- **政策研究优先级**：连续性 × 结构位置 × 明确机制/项目；
- **产业景气优先级**：需求 × 供给约束 × 价格/利润传导；
- **证券吸引力**：公司质量 × 盈利兑现 × 估值 × 证伪风险。

用户没有提供风险预算、持仓和期限时，输出“研究组合”或“示例组合”，并保留现金/未分配权重。高相关主题合并计算产业链暴露，不能用股票数量假装分散。

组合规则应由证据触发：盈利上修快于估值扩张才增加高增长权重；收入、现金流和毛利率至少两项弱于逻辑预期时下调；项目清单或政策标题不能单独触发加仓。

## 7. 决策收口

最终表格至少分开：方向、执行证据、产业状态、代表公司、当前估值、主要风险、下一验证点。明确哪些属于已兑现、正在传导、仅有预期或证据不足。

结论使用“重点研究、等待细则、等待财务验证、估值过度、暂不配置”等状态；避免把政策确定性写成收益确定性。
