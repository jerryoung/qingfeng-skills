# 中国政策纵向投资分析

把政策文本拆成四层证据：**文本事实 → 结构变化 → 执行兑现 → 投资价值**。结论必须能回到原文、年度资金或公司披露，不能由热词直接跳到买入建议。

## 按任务加载

- 所有任务先读 [纵向比较方法](references/methodology.md)，完成语料冻结、结构编码和关键词口径。
- 用户要求行业、公司、估值或组合结论时，再读 [投资证据链](references/investment-evidence.md)。
- 用户要求公众号、公开发布或政治敏感脱敏时，再读 [公开发布与脱敏](references/publication.md)。

## 工作流

### 1. 冻结语料

先运行 `date`，记录研究日和数据截止日。为每份文件登记标题、规划期、版本、发布日期、批准/发布机关、文件状态、官方链接或本地路径、正文边界与哈希。

优先使用正式纲要、中央《建议》、起草说明、人大批准文本、政府预算和项目清单。官方全文缺失时标记“未找到”，保留检索范围；转载或评论只能作为线索，不能无声明地替代正式版本。

完成标准：每份进入比较的文本都能唯一定位版本，目录、正文、专栏是否纳入统计均已写明。

### 2. 结构先行

先比较一级结构、篇、章、节、指标和重大工程，再看词频。对每个主题编码为：连续、升格、降格、前移、后移、拆分、合并、新增、任务转型或退出。

“篇章减少”不自动等于事项减少；“由篇降章”不自动等于政策取消。必须结合新容器的名称、位置和正文任务判断。

完成标准：每项结构变化都引用前后两期的标题、层级和位置；长期连续性与本期增量分开呈现。

### 3. 关键词只做探针

关键词用于发现变化，不是重要性分数。统计时同时给出原始次数和每万汉字频率，并记录版本、正文边界、目录/专栏口径、同义词是否合并。

可运行：

```bash
python3 scripts/analyze_policy_corpus.py <files-or-directory> \
  --keywords "人工智能,创新,消费,安全" \
  --format markdown
```

脚本只提供可复现统计和标题候选；目录重复、旧 PDF 字体、OCR 错误与语义归并仍需人工复核。

完成标准：任何基于词频的结论都已回到正文语境，且不同版本或统计边界没有被混用。

### 4. 区分文本信号与执行状态

对关键方向标注当前所处状态：方向性表述、正式规划任务、年度预算授权、资金下达、项目清单、拨付、开工、招标、中标、公司订单、收入确认、现金回款。

预算数不等于支付数；项目入表不等于开工；订单不等于收入；利润不等于现金。

完成标准：每个“已经落地”的表述都有对应状态证据，尚未跨越的下一层被明确写出。

### 5. 投资扩展

只有用户要求投资含义时才执行：先验证行业供需、资本开支、价格、库存和利润率，再验证公司收入暴露、竞争壁垒、财务质量和当前估值。把“政策研究优先级”与“证券买入优先级”分开排序。

使用最新已披露实绩；未披露期返回缺失，不以预测值冒充实际值。金融数据出现币种、单位或口径冲突时停止使用该指标，回到原始披露核验。

### 6. 交付与证伪

默认结论包含：长期不变的骨架、本期结构增量、关键词迁移、执行证据、受益与承压环节、代表公司观察池、估值边界、证伪指标和下一次更新节点。

没有用户风险预算与持仓信息时，只给研究组合或示例权重，并明确不能直接执行。结尾区分数据置信度、政策兑现置信度与投资确定性。

## 不越过的边界

- 姓名次数只能证明文本位置和表述变化，不能单独证明权力、动机、执行效果或社会状态。
- 规划方向可以提高需求概率，不能保证行业利润率、公司回报或股票收益。
- 未来五年尚未发生，不把历史景气验证写成未来收益回测。
- 来源冲突时并列口径并追溯原始文件；找不到就保留缺口，不填充叙事。
